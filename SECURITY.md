# Security Policy

This is a static Jekyll site with no user accounts, no database, and no server-side code beyond build-time processing. The attack surface is very limited.

## Reporting a Vulnerability

If you discover a security issue (e.g. a malicious workout script, XSS in a template, or a problem with the GymScript import deep-link), please report it privately:

**Email:** jacob@saxberg.dk

Please include a description of the issue and steps to reproduce it. You can expect an acknowledgement within 48 hours.

Do not open a public GitHub issue for security vulnerabilities.
